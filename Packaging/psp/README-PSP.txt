DevilutionX PSP installation

Extract this ZIP into ms0:/PSP/GAME/DevilutionX/ (or the equivalent
PPSSPP game folder). Keep the directory structure intact:

  EBOOT.PBP
  assets/fonts/12-00.clx
  assets/fonts/grayuis.trn
  assets/ui_art/mainmenuw.clx
  assets/data/charbg.clx

All other files under assets/ must stay in their subdirectories too.
If your extractor creates a single file named assets\fonts\12-00.clx,
it has not created the required assets/fonts/ directory structure.

Copy DIABDAT.MPQ from your own Diablo installation next to EBOOT.PBP.
For Hellfire, also copy hellfire.mpq, hfmonk.mpq, hfmusic.mpq, and
hfvoice.mpq from your own Hellfire installation to that same folder.
These commercial game files are not included in this ZIP.

Use the assets/ directory supplied with this EBOOT.PBP. A separate
devilutionx.mpq is not needed. Remove any older devilutionx.mpq from
the game folder because it can override or conflict with these assets.
